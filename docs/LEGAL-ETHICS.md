- 状態: 2026-11-20、mi 指示「法律、倫理層を作り判断して」を
  受けて作成。本書が本製品の法律・倫理ガバナンスの正本である。
- 対象: `docs/CHARACTER-SYSTEM.md`（キャラクター生成システム
  設計）と `docs/gap-items.csv`（棚卸し 9,034 項目）。
- 項目レベルの判定: **`docs/legal-ethics-verdicts.csv`**
  （4,229 件にフラグ付け。範囲と数え方は §7）。
- **免責（重要）**: 本書は設計ガバナンスのための内部文書であり、
  **法的助言ではない**。法令の解釈には不確かな点が残る箇所が
  あり、それらは本文に「不確か」と明記した。公開前に弁護士に
  よる確認が必要な項目は §8 に指定した。本書の判定は、その
  確認を代替しない。

## 1. 目的と原則

### 1.1 目的

本製品は「アバター生成＋試着＋共有カード」を、ニコニコ動画
等の公開プラットフォームでの認知獲得を目的として広める
想定の製品である。民族・年齢・性別・体型・文化的衣服・
遺伝合成・シード共有といった要素は、法律と倫理の両方に
触れる。本層の目的は、それらを**事前に審査し、条件を付けて
前に進める**ことにある。

### 1.2 原則

1. **萎縮させない。** 「危ないから全部禁止」は層の失敗と
   する。各論点はまず「どういう条件なら許可できるか」を
   検討し、禁止は条件を付けてもなお越えるべきでない線に
   限る。本書の判定で項目レベルの「禁止」は 0 件であり、
   禁止は機能・組合せのレベルに置いた（§6 の判断記録）。
2. **越えてはならない線は明確に禁止する。** 未成年（18歳
   未満）相当の人物の生成と、その性的文脈での使用は、その
   代表である。ここは条件付き許可にしない。
3. **法と規範を分けて書く。** 日本法で適法でも、公開先
   プラットフォームの規範や他法域の法で禁止されることが
   ある。製品のリスクは後者でも生じるため、両方を根拠に
   挙げる。
4. **判断は記録する。** 判定・条件・理由・根拠を本書と
   CSV に残し、後から覆す場合は覆した記録も残す。

## 2. 製品の前提事実（審査の土台）

審査は次の事実を前提に行った。これらが変われば再審査が
必要である（§5.4）。

- 生成は全てコードによる手続き的生成であり、学習モデル
  （生成AI）も外部素材も使わない。
- 人物は架空のマネキン的アバターであり、写真・スキャン等
  の実在人物データを取り込む機能は存在しない。
- 作成者は個人データを持たない（サーバなし、端末内処理
  のみ）。保存・共有はパラメータ（シード）と端末内で生成
  した画像（共有カード）のみによる。
- 課金・広告・解析は存在しない（不変条件テストで固定）。
- 操作の中心は「服を着せる」ことであり、脱衣状態の提示
  を目的とする機能はない。衣服の下には不透明なベース
  レイヤー（マネキンの体表）がある。
- 公開・拡散の想定先は、ニコニコ動画、YouTube、X 等の
  一般公開プラットフォームと Web 一般である。

## 3. 適用される法と規範の棚卸し

### 3.1 児童の保護（最重要論点）

年齢表現と着せ替え（衣服の付け外し）の組合せが、本製品で
最も慎重を要する領域である。

**日本法:**

- **児童買春、児童ポルノに係る行為等の規制及び処罰並びに
  児童の保護等に関する法律**（平成11年法律第52号）第2条:
  「児童」は18歳未満。同条第3項の「児童ポルノ」は、最高裁
  令和2年1月27日決定により「実在する児童の姿態を描写した
  もの」に限られ、**実在しない児童の姿態を描写した漫画・
  CG は含まない**と明確化された。ただし、実在児童の写真等
  を基に描き起こした CG は「実在する児童の姿態の描写」と
  して同法の対象になりうる（同決定の射程）。本製品は実在
  人物データを取り込まないため、この類型には当たらない。
- **刑法第175条**（わいせつ物頒布等）: わいせつな電磁的
  記録等の頒布・公然陳列を処罰する。描写対象の実在性は
  要件ではなく、架空の人物の描写でも「わいせつ」に当た
  れば対象になりうる。本製品はわいせつ表現を扱わない
  前提だが、露出度の高い機能を将来追加する場合はこの
  射程を再確認する。
- **東京都青少年の健全な育成に関する条例**第8条（不健全
  図書指定）: 表示・描写から18歳未満と認められる者の性交
  等を性的対象として肯定的に描写した図書類等を指定し、
  青少年への販売・閲覧を制限できる。これは販売規制で
  あって創作・所持自体の禁止ではないが、「年齢が明示・
  示唆されるキャラクターの性的描写」への社会的要請の
  水準を示す参照として置く。

**他法域（公開先の法）:**

- 米国: 18 U.S.C. §1466A は、未成年が性的行為を行う
  **わいせつな視覚的描写**を、描画・CG であっても、実在の
  未成年が存在しなくても連邦犯罪とする。日本法とは結論
  が異なる代表例である。
- 英国: Coroners and Justice Act 2009 第62条は、児童の
  禁止画像（写真でない画像を含む）の所持を処罰する。
- カナダ: 刑法第163.1条の定義は視覚的表現に描画を含む。
- つまり「架空だから安全」は日本法の話にすぎず、公開が
  国境を越える以上、設計の線は最も厳しい主要法域と
  プラットフォーム規範に合わせて引くのが合理的である。

**プラットフォーム規範:**

- **ニコニコ規約／ニコニコ活動ガイドライン**（2024年
  10月30日改定）: 「コンテンツがアクセスまたは配信される
  国・地域の法令上定義される、児童または児童を想起させる
  人物を対象とした、虐待、性的搾取、性交に従事している
  ように見えるコンテンツ」を規制対象とし、日本国外の
  法令も考慮すると明示された。本製品の主要な公開先の
  規範として最も直接的である。
  https://blog.nicovideo.jp/niconews/1540
- **YouTube 子どもの安全に関するポリシー**: 未成年者の
  性的対象化を禁止する。
  https://support.google.com/youtube/answer/2801999
- **X 児童の性的搾取ポリシー**: ゼロトレランスであり、
  「イラスト、コンピュータ生成、その他の形式の写実的な
  児童の性的文脈での描写」を明示的に対象に含む。
  https://help.x.com/en/rules-and-policies/child-safety
- **App Store Review Guidelines** 1.1.4／1.2（あからさまに
  性的な素材の禁止、ユーザー生成コンテンツへの対応要件）、
  **Google Play** の性的コンテンツおよび児童の危険に
  関するポリシー（未成年者の性的対象化の禁止、違反時は
  即時削除）: 将来ストア配布を行う場合の規範として参照
  する（現行の配布形態は Web）。

**本層の結論（§6 判断 J-02 の土台）:** 日本法上は架空人物
の描写自体は直ちに違法ではない。しかし本製品は「衣服の
付け外し」という操作を含むため、未成年相当の人物を生成
可能にすること自体が、プラットフォーム規範違反と他法域
リスクの入口になる。よって線は「未成年相当の人物は生成
できない」に引く。これは過剰規制ではなく、製品の存続
条件である。

### 3.2 肖像・パブリシティ・人格権（実在人物の再現）

- **肖像権**は明文法がなく、人格権の一内容として判例法理
  で保護される。一般人の肖像も対象である。
- **パブリシティ権**: 最高裁平成24年2月2日判決（ピンク・
  レディー事件、民集66巻2号89頁）は、氏名・肖像等を
  ①独立して鑑賞の対象となる商品等として使用する、
  ②商品等の差別化を図る目的で商品等に付す、③商品等の
  広告として使用する、といった「専ら顧客吸引力の利用を
  目的とする」場合に侵害が成立するとした。本製品の公式
  プリセットや共有カードの見本に実在の著名人を使えば、
  この類型に近づく。
  https://ja.wikipedia.org/wiki/パブリシティ権
- **名誉毀損**（刑法第230条）: 実在人物の性的・侮辱的な
  合成表現は、刑事・民事の両面で問題になりうる。
- **私事性的画像記録の提供等による被害の防止に関する
  法律**（平成26年法律第126号）: 同意なく私事性的画像を
  提供する行為を処罰するが、対象は「撮影された」画像が
  前提であり、完全な合成画像への適用範囲には解釈の
  争いがある（**不確か**と明記する）。ただし解釈がどう
  あれ、実在人物の性的ディープフェイク的利用は本製品の
  規約で禁止すべき行為であることに変わりはない。
- 米国 **TAKE IT DOWN Act**（2025年成立、Pub. L. 119-12）:
  実在人物の同意のない性的画像（デジタルフォージェリを
  含む）の公開を犯罪化した。利用者が本製品で実在人物を
  再現し性的文脈で拡散する行為は、法域によってはこの
  類型にも触れる。

**結論:** 実在人物の再現は、製品側がプリセットとして提供
することを**禁止**し、利用者がパラメータ操作で似せてしまう
ことについては技術的に完全には防げないため、利用規約と
UI 上の明示で担保する（判断 J-08）。写真・スキャンの
取り込み機能を将来追加する場合は、この論点の再審査を
必須とする（現設計には存在しない）。

### 3.3 著作権・商標（実在ブランド・キャラクター意匠）

- **著作権法**: キャラクターという抽象的概念自体は著作物
  ではないが、具体的に表現された絵画・デザインは著作物
  として保護されうる。実在のアニメ・ゲームキャラクター
  の衣装や容貌を再現するプリセット・柄は、著作権侵害の
  リスクがある。
- **商標法／不正競争防止法**: 実在ブランドのロゴ・著名な
  商品表示を衣服の柄等に使う行為は、商標権侵害や周知
  表示の冒用に当たりうる。
- **結論:** 製品に同梱・公式提供する衣服・柄・プリセット
  は全て自作とし、実在ブランドのロゴ・商標、著作権で
  保護された意匠の複製を**禁止**する（判断 J-09）。
  利用者が外部画像を持ち込む機能は現設計に存在しない。
  追加する場合は再審査必須。

### 3.4 プライバシー・個人情報（シードと共有カード）

- **個人情報保護法**第2条、**GDPR** 第4条第1号: 個人
  情報／個人データは「特定の個人を識別できる情報」で
  ある。架空人物のパラメータ値の集合（シード）は、それ
  自体では誰の個人情報でもない。本製品がサーバを持たず
  個人データを収集しない設計は、この点で構造的に安全
  である。
- ただし例外がある。利用者がシードやパラメータを使って
  **実在の特定個人を識別可能な形で再現**した場合、その
  データは当該個人に関する情報となりうる。また顔パラ
  メータは生体認証テンプレートではないが、人物の同定に
  資する情報である点で、通常の数値設定より慎重な扱いが
  要る。
